# Data

`diabetes.csv` is not included. It is the widely shared **Pima Indians Diabetes Database** (National Institute of Diabetes and Digestive and Kidney Diseases), with 768 rows, eight input columns and an `Outcome` column (0 = not diabetic, 1 = diabetic).

To get it:

1. Search for "Pima Indians Diabetes Database" on the UCI Machine Learning Repository or Kaggle and open the dataset page.
2. Check the licence and terms on that page.
3. Download `diabetes.csv` and place it in the repository root (next to `app.py`).

`diabetes.csv` is ignored by `.gitignore` so it is not committed by accident.
